# Arpita Kumari Gupta — Developer Portfolio

A recruiter-focused React + Vite portfolio for **Web Development / Software Development** opportunities, with **Digital Marketing** noted as a secondary interest.

## Positioning

- **Primary:** Web Development / Software Development
- **Secondary interest:** Digital Marketing & SEO fundamentals
- **Current role:** Tele Associate at IndiaMART
- **Education:** BCA, MMHAPU Patna (2023–2026)
- **Location:** Patna, Bihar, India

## Verified skills

- **Current skills:** HTML, CSS, JavaScript, MySQL, SQL, C
- **Currently learning:** Java

React, Node.js and Express are **not** listed as personal skills. They appear only in the Smart Kirana project card, labelled "Built with (project tech stack)", because that's what the project itself is built on — this keeps the portfolio honest about what's a personal skill versus what's project-specific technology.

## Highlights

- Responsive, recruiter-first single-page layout
- Clear primary (Web Dev/SDE) vs secondary (Digital Marketing) career positioning
- Current work experience section (IndiaMART — Tele Associate)
- Smart Kirana Management System featured project: dashboard, products, stock, customers, purchases, sales/billing, credit, expenses, reports and user management screens
- 36 real project screenshots grouped by module, with an accessible lightbox (click to open, Next/Previous buttons, Left/Right arrow keys, Escape to close, live "X of 36" caption)
- Dark/light theme toggle (persisted in localStorage)
- Mobile-first responsive navigation
- Working "Download Resume" button linked to the actual resume PDF
- Direct email link (`mailto:`) plus a contact form that opens a pre-filled email in the visitor's own email app — no fake "message sent" confirmation, no backend required
- LinkedIn and GitHub CTAs using the real, exact profile URLs
- SEO metadata: description, keywords, canonical link, Open Graph and Twitter card tags, favicon
- `prefers-reduced-motion` respected throughout (loader, scroll reveals, hover transforms)

## Run locally

```bash
npm install
npm run lint
npm run build
npm run dev
```

## Included personal assets

- `public/images/profile.jpg` — profile photo
- `public/resume.pdf` — resume PDF
- `public/images/smart-kirana/` — 36 real Smart Kirana Management System screenshots

## Deployment

The project is Vite-based and can be deployed to Vercel, Netlify, GitHub Pages (via the included `gh-pages` script: `npm run deploy`) or another static hosting provider.
